# Домашній бюджет

Курсова робота: настільний застосунок для обліку доходів і витрат на Python та Tkinter.

## Можливості

- додавання, редагування й видалення транзакцій та категорій;
- пошук, фільтрація і сортування транзакцій;
- імпорт та експорт JSON, експорт звіту в XML;
- місячні звіти й контроль лімітів;
- асинхронне завантаження великих наборів даних і перемикання теми.

## Запуск

Потрібен Python 3.10 або новіший із Tkinter.

```powershell
py -3 main.py
```

Для перегляду демонстраційних записів імпортуйте `sample_budget.json` через кнопку «Імпорт JSON». Застосунок збереже робочі дані в `budget.json`, який не додається до Git.

## Тести

```powershell
py -3 -m unittest discover -s tests -v
```

## Генерація даних і benchmark

```powershell
py -3 generate_data.py sample_budget.json --count 120 --days 90 --seed 42
py -3 benchmark.py test_10000.json
```

`sample_budget.json` і `test_10000.json` містять згенеровані демонстраційні дані.
